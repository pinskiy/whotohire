# Кого вы ищете на самом деле?

Бесплатный тест для компаний: какой специалист по коммуникациям, бренду или продвижению им нужен на самом деле. В конце — название вакансии, цели на год и черновик текста вакансии.

Статичный сайт на одном файле `index.html`, без cookie, аналитики и внешних запросов. Шрифты Unbounded и Golos Text лежат в `fonts/` (SIL Open Font License).
